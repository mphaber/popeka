# Rainbow Pop

A bright, brain-off bubble-popping game for kids and adults. Tap any connected group of two or more matching color bubbles to pop the whole group, bubbles fall, empty columns slide together, and the goal is to clear the board. Every color carries its own symbol, leftover single bubbles pop themselves in a celebration finish, and the one extra element is a wild rainbow bubble from level 9.

- 30 short levels, every board generated to be clearable, all levels open from the start
- Tutorial inside the game: level 1 teaches the move, level 9 introduces the rainbow bubble
- Stars for beating par, never required for progress
- Forgiving throughout: unlimited undo, free restart, resume where you left off
- No timers, no lives, no ads, no purchases

Play: https://mphaber.github.io/rainbow-/
