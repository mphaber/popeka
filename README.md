# Rainbow Rings

A bright, poppy color-sorting puzzle game for kids and adults. Tap a ring to spin it one step clockwise and line the colors up into solid wedges. Every color carries its own symbol, chained rings spin together from level 5, and the final levels are sunbursts with different segment counts per ring.

- 40 short levels, every one scrambled from a solved rainbow so it is always solvable
- Stars for beating par, never required for progress
- Forgiving throughout: unlimited undo, exact hints, free restart, skip any level, resume where you left off
- No timers, no lives, no ads, no purchases
